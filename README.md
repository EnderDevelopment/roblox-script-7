# Roblox Weapon Script

This project contains a script for a shootable automatic assault rifle with a cool VFX effect. The script includes features like adjustable fire rate, bullet physics, sound effects, and particle effects. It also handles hit detection and damage application to humanoids.

## Install

1. Download the `WeaponScript.server.lua` file from the project repository.
2. Open Roblox Studio.
3. Create a new model for the weapon.
4. Insert the `WeaponScript.server.lua` script into the weapon model.

## Use

1. Customize the weapon properties as needed in the script.
2. Test the weapon in-game by equipping it to a character and using the left mouse button to fire.
